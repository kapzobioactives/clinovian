# Clinovian release notes — 16 July 2026

This release is a full remediation of the July 2026 business, clinical, regulatory, content, technical and credibility audit.

## Major changes

- Replaced conflicting deployment files with one Vercel configuration and explicit page/legacy routes.
- Corrected the Formspree Content Security Policy and synchronized every service selector/query-string value.
- Rebuilt the DRG and observation specimens to correct the AKI/ATN, MCC, staging, payer-applicability and timestamp errors.
- Reworked all eight specimens with fictional assumptions, version/date control, source registers, stable evidence locators, limitations and client/Clinovian responsibility boundaries.
- Added eight downloadable, print-tested specimen PDFs generated from the final HTML/CSS.
- Rebuilt all eight insight articles with named authorship, dates, primary sources, scope notes and qualified claims.
- Removed unsupported payment deltas, recovery forecasts, generalized overturn rates and categorical payer/clinical statements.
- Established one canonical catalog for nine services, prices, units, turnaround clocks and scope limits.
- Expanded pricing, payment, cancellation, revision, refund, deadline, outcome and recurring-capacity terms.
- Added Trust Center, Editorial Policy, Accessibility statement and stronger privacy/security/terms disclosures.
- Clarified founder-authored staffing, qualification evidence, U.S. licensure/coding/legal boundaries, insurance status and subprocessor/AI disclosure.
- Added complete metadata, Article/FAQ/ProfessionalService schema, icons, RSS, sitemap `lastmod`, robots controls and legacy redirects.
- Removed obsolete samples, false QA artifacts, legacy “pilot/desk” language, inline styles, `!important` rules and dormant CSS.
- Added responsive tables, mobile overflow controls, larger targets, focus management, field-level errors, reduced-motion support and in-document specimen navigation.
- Added a strict release validator, sitemap generator, preview checker and deployment checklist.

## Release boundary

The build is internally consistent and statically validated. Live Vercel routing/headers, Formspree delivery, real-device/browser behavior, assistive-technology behavior, penetration/security testing and independent legal/coding/compliance review remain deployment-owner checks.
